# Security policy

## Supported versions

Only the latest 0.3.x release gets security fixes. A fix comes out as a new release, and older versions are not
patched, so please update first and check whether the problem is still there. `pocketvina --version` shows the
version you have.

| Version                | Supported |
| ---------------------- | --------- |
| Latest 0.3.x release   | Yes       |
| Older releases         | No        |

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through GitHub instead: open the
[reporting form](https://github.com/BIMSBbioinfo/PocketVina/security/advisories/new), or go to the
"Security and quality" tab of this repository and click "Report a vulnerability". Only you and the maintainers can
see the report.

Tell us the PocketVina version, what the problem is and how to reproduce it.

## What happens next

We reply in the report, where we may ask you for details. If we confirm the problem, we fix it in a new release and
then publish a security advisory, with credit to you unless you would rather not be named. If we find that it is not a
security problem, we tell you why.
